## Objective

Recommendation systems often have limited interaction data for individual users and items. This project investigated how additional information could support recommendations when those interactions are sparse.

## Approach

I implemented the model described in **A deep learning based trust- and tag-aware recommender system** using the **Last.fm dataset**. The implementation used sparse autoencoders to encode user social trust and user tags, bringing those signals into the recommendation process.

## Technical focus

Built in Python and TensorFlow, the project examined how learned representations of social trust and tagging information could complement sparse interaction data within a recommendation model.
