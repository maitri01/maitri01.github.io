## My role

I designed and implemented eight challenges, making the task-level decisions about **datasets, models, and experimental parameters**. My work turned research ideas into practical tasks that participants could train, test, and evaluate.

I attended all seven venues and supported participants with task-related questions, technical troubleshooting, and GPU infrastructure issues.

## Challenges I built

| Challenge | Focus |
| --- | --- |
| P2 Image Attribution | Identifying the source of generated images |
| P3 Watermark Detection | Detecting watermarks in images |
| V3 Watermark Removal | Removing image watermark signals |
| S2 Model Tracer | Tracing generative models |
| W3 LLM Watermark Detection | Detecting watermarks in generated text |
| B3 LLM Watermark Removal | Removing text watermark signals |
| F3 LocalizeWatermark | Localising image watermark signals |
| F4 Unlearning | Evaluating machine unlearning |

## From experiments to a live event

The work combined experimental design with practical engineering. Beyond implementing tasks, I helped participants work through model, environment, and compute issues during the competitions.
