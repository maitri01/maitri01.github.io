# Maitri Shah Portfolio (Astro + Tailwind)

Professional multi-page portfolio built with Astro and Tailwind CSS.

## Stack

- Astro
- Tailwind CSS
- Playwright

## Pages

- `/` Home
- `/work-experience/`
- `/projects/`
- `/cv-background/`

## Development

```bash
npm install
npm run dev
npm run build
npm run test:e2e
```
